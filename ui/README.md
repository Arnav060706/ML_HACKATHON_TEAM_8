# PathSnap Evaluator UI (Laptop 2)

Standalone browser interface for the evaluation stage of the PathSnap hackathon.

## Usage Instructions
1. Open `ui/index.html` in any modern web browser on Laptop 2.
2. In the "Laptop 1 API Host" field, enter the IP address and port of Laptop 1 (e.g. `http://192.168.1.50:8000`).
3. Select any of the 10 evaluation trips from the dropdown.
4. Toggle HMM/Viterbi decoding as desired and click **Reconstruct Route**.
5. The UI displays the reconstructed road arcs, total points matched, latency, and full JSON payload.
